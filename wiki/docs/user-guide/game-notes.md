# Game Notes

Each game has its own markdown notes. A note is a normal `.md` file in the
game's folder, so it stays readable outside the app, plus a few details the app
keeps beside it.

## Writing

Notes use markdown, and long lines wrap instead of running off the page.
Checklists work: write `- [ ] item` and click the box to tick it. A note's card
shows how many tasks are done, like 3 of 8.

A new note can start from a template, which fills in a title, some tags and a
body you then change freely:

- Boss tips
- Build
- Route or walkthrough
- Collectibles
- Checklist
- Play log

## Details kept with a note

| Detail | What it does |
| --- | --- |
| Created date | Shown on the card. For notes written before this existed, it is the file's modified date. |
| Pin | A pinned note stays at the top of the list. |
| Tags | Used for finding and sorting notes. |
| Achievement | Ties the note to one of the game's achievements. The achievement's page lists the notes tied to it. |

## Finding notes

- **Search notes** looks through every note in the game.
- Sort by Recently edited, Newest created or Name.
- **Search your games** looks through the notes of every game at once. The same
  search is in the command palette.

## Working with a note

- **Duplicate** makes a copy.
- **Move** sends a note to another game.
- **Rename** keeps the content. A title that is already used is refused rather
  than overwriting the other note.

## History

Every time you save changes, the text it replaced is kept as a version. A note
keeps its last 30 versions. Open **History** to read an earlier version or
restore it. Restoring keeps what was there as a version first, so a restore can
be undone.
