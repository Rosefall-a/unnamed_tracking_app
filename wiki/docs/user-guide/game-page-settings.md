# Game Page Settings

You choose what a game's page shows. There is one set of defaults for every
game, and any single game can override part of it.

- **Defaults:** Settings, then **Game Page**.
- **One game:** the **Page** tab in that game's Edit dialog. Only what you
  change there is stored; everything else keeps following the defaults.

## Tabs

Each optional tab is set to one of three modes:

| Mode | Meaning |
| --- | --- |
| Show | Always visible. |
| Hide | Never visible. |
| Auto | Visible once the game has something in it. |

The optional tabs are Achievements, Screenshots, Clips, Soundtrack, Saves,
Docs, Notes and Stats. Overview is always there. A tab on Auto that is still
empty is tucked into a **+** menu, one click away. A tab set to Hide is not
shown anywhere, except that the tab you are currently on is never hidden from
you.

Hiding Achievements also removes everything that depends on them: the
achievement badge, the achievement stats, and tying files and notes to
achievements.

**Opens on** picks the tab a game opens with. A link that names a tab, such as
one from an achievement, still goes to that tab.

## Parts of the header

These can be turned off individually:

- the score button (and the score in the stats);
- the collections button;
- the favorite heart;
- the developer and publisher line;
- the date added badge;
- the platform badge;
- the history timeline in Stats (the numbers stay).

## Examples

- Turn Saves, Docs and Soundtrack to **Auto** in the defaults so a game only
  shows them once you add something.
- Set Achievements to **Hide** on a single game that has none worth tracking.
- Set Clips to **Show** on the one game you record constantly.
