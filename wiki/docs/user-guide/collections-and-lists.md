# Collections

Games have **Collections**, and so do Movies, TV and Anime (under Media). They
look and behave the same way: a grid of cards, each showing a 2x2 collage of the
first posters, and a page for each one.

## The overview page

| Control | What it does |
| --- | --- |
| Search | Filters by name. |
| Sort | **My order** (default), Name, or most games or titles. Media collections also sort by Recently updated. |
| All, Manual, Smart | Show every one, only the ones you fill yourself, or only the ones that fill themselves. |
| Type (Media only) | Any type, Movies, TV Shows or Anime. |
| Pin | A pinned card stays at the front of the page. Pinned cards and the rest are ordered separately. |
| Edit, Delete | On hover. A card the app keeps for you cannot be edited or deleted. |

### My order

With the sort on **My order** and nothing filtered, each card shows arrows to
move it earlier or later, and you can drag a card onto another to put it in
that place. The order is saved as you go. Moving is switched off while a search
or filter hides some cards, because the position would be unclear.

## Manual and smart

- A **manual** collection holds what you add to it, from its page
  (**+ Add Games** or **+ Add Titles**) or from the collection button on a game,
  movie, show or anime.
- A **smart** one fills itself from a rule and always matches what your library
  looks like right now. It has no add, remove or reorder, only its rule.

A game collection's rule uses one of: status, playtime in hours, favorite, tag
or source. A media collection's rule can combine media types, status groups, a genre, a
minimum score and favorites.

**Favorites** is a smart collection the app keeps for every user. It shows the
games you have hearted.

## Inside one

The page shows the count, a **Smart** tag if it is one, and:

- **Sort**: Manual order, Title or Status.
- **Reorder**: drag tiles or use the arrows. It saves as you go.
- **Star**: on a tile, uses that title's poster as the cover of the whole
  collection. Without a pick, the first item is the cover.
- **Remove**: takes a title out (manual ones only).
- **Edit** and **Delete**. Deleting never deletes the games or titles in it.

A collection can sit inside another by naming it **Parent/Child**. The card
shows the parent above the name, and the collection's own page links back to the
parent.

## Where it is stored

Which games are in a collection is stored on the server with the game. The rest
of a game collection (smart rules, empty collections, descriptions, pins, "My
order" and cover picks) is currently kept in your browser, so it does not follow
you to another browser or device. Media collections are stored on the server in full.
