# Preserved UI concept gallery

Extract this archive into a folder and open `concepts.html` in a browser. No application server, account, package installation or build is needed. Share the complete ZIP so the preview and editable source remain together.

The gallery preserves the Archive, Pocket and Studio proposals. Use its controls to switch design, page, light/dark mode, viewport and account role. Data and local interactions are illustrative. The implemented application uses Pocket navigation/mobile controls with Archive's desktop structure; these proposals remain references for possible future styles.

`concept-source.html` is the editable fragment. `concepts.html` is the standalone preview containing that fragment. Both are versioned alongside the application and the archive can be reproduced with `python tools/archive_ui_concepts.py` from the repository. The gallery needs no network connection.
