# Context Map

## Backend (Python)
- FastAPI app in src/backend/src
- Database models in src/backend/database
- Services in src/backend/services
- Alembic migrations via alembic.ini
- Dependencies in pyproject.toml + requirements.txt

## Frontend (TypeScript)
- Vite project in src/frontend
- Components in src/frontend/src
- Public assets in src/frontend/public
- Configs: tsconfig.json, vite.config.ts

## Docker
- compose.yaml orchestrates backend + frontend
- example-docker-compose.yaml is reference

## Scripts
- generate-the-.env.-please.sh creates environment files
